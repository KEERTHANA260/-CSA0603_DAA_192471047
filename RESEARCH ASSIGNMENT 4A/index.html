An interactive companion to DAA Assignment 4 – Part I (CO4). Each task has its decision rule or recurrence, and a tracer you can run on the assignment’s own data or on your own. Edit the inputs to challenge a design.

Each input line is one item, separated by spaces. The tracers are for checking your hand traces; the assignment itself must be answered in pseudocode.

Task 1 · 6 marks

Repair the vehicle-loading design

Packages can be divided, so the greedy rule is to take the highest value-to-weight ratio first and split the last package if it does not fit.

ratio = value / weight → take whole if weight ≤ remaining, else take remaining / weight
Task 2 · 8 marks

Job sequencing with deadlines

Consider jobs by descending profit and place each in the latest free slot that is not after its deadline. A job with no free slot is rejected.

Task 3 · 9 marks

0/1 Knapsack by dynamic programming

DP[i][w] is the best value using the first i items with capacity w. Highlighted cells are the states that reconstruct the chosen items.

DP[i][w] = DP[i−1][w] if weight[i] > w
DP[i][w] = MAX(DP[i−1][w], value[i] + DP[i−1][w−weight[i]]) otherwise
Task 4 · 7 marks

WordBreak forensics

The original code accepts a dictionary word ending at i without checking that the text before it can be segmented. The repair adds DP[j] = TRUE to the condition.

Task 5 · 7 marks

One graph, three kinds of reasoning

The greedy method finalises a vertex when it is closest. A negative edge can make that wrong. Bellman-Ford keeps relaxing, and Floyd builds all-pairs distances through a growing set of intermediate vertices.

Task 6 · 13 marks

Energy-aware job scheduling

Sort jobs by finish time. OPT[j] is the best value from the first j jobs, and p(j) is the last job that finishes by the time job j starts. Take job j only when value + OPT[p(j)] is strictly greater than OPT[j−1].

OPT[j] = MAX(OPT[j−1], value[j] + OPT[p(j)]), OPT[0] = 0
