# DAA Assignment 4A – Algorithmic Design Through Pseudocode (Interactive Companion)

An interactive website for **Design and Analysis of Algorithms – Assignment 4, Part I (CO4)**.
Each task has its decision rule or recurrence and a tracer you can run on the assignment data or on your own input.

| Task | Topic | What you can run |
|---|---|---|
| 1 | Fractional vehicle loading (greedy) | Ratio-based loading trace |
| 2 | Job sequencing with deadlines | Slot-by-slot placement, modified-case button |
| 3 | 0/1 Knapsack (DP) | DP table with reconstruction path highlighted |
| 4 | WordBreak forensics | Original vs repaired DP, first wrong state |
| 5 | Dijkstra, Bellman-Ford, Floyd | Greedy vs Bellman-Ford, negative-edge example, all-pairs matrix |
| 6 | Energy-aware job scheduling (weighted intervals) | p(j), OPT table, selected jobs, greedy comparison, adversarial set |

## Run locally
No build step. Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Push this folder to a new GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. The site appears at `https://<your-username>.github.io/<repo-name>/`.
